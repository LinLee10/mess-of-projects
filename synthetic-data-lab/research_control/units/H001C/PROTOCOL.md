H001 completed three generation seeds with five tree students per seed. All artifacts were retrieved and all 58 file digests per seed verified. Separate full table checks reproduced every declared hard rule, marginal, class conditional, tail, query, copying and diversity result. The contextual calibration gain over raw interpolation was positive in all three seeds, with mean 1.71 percentage points in balanced accuracy. Mean rarest class recall decreased by 1.36 points. This is a candidate, not a promoted universal quality winner.

This next bounded unit challenges whether the result is specific to the boosted tree learner. Convergence is a gate, not a warning to silently discard.
