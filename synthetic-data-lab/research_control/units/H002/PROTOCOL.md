# H002 exact conditional marginal dependence probe

B002 run 35270306642 completed and its retrieved archive and all internal file digests passed. The conditional Gaussian copula achieved 76.31 percent tree balanced accuracy and 50.65 percent linear balanced accuracy on seed17 development data. No final holdout was scored.

This experiment follows the question suggested by that baseline: can retaining empirical joint ranks improve dependency and utility when every method has exactly the same context specific marginals? The working hypothesis is that the Gaussian dependence approximation loses higher order combinations despite accurate individual columns. A second hypothesis is that a broader perturbation trades utility for lower similarity to training points. Neither is a priority claim.

Use all 348563 recovered training rows and all 116314 development rows. The reserved partition remains unscored and historical exposure remains unknown. Within each wilderness, soil and forest cover context, each method must output exactly the original number of records and the exact original multiset of values in each numerical column. These are new combinations of empirical feature values, not independent new real observations. Class frequencies are not balanced artificially.

Four prespecified variants are Gaussian rank rearrangement, empirical beta rank smoothing, ninefold wider beta smoothing, and an independent column ordering negative control. Empirical beta latent draws use Beta(r, n+1-r) with identity keyed randomized tied ranks. The wider variant divides both beta shape parameters by nine. The standard beta copula uniform margin theorem does not apply to this wider kernel; exact finite marginal assignment enforces the declared empirical constraints afterward. One anchor is used per training row before final output permutation, so finite tables are stratified rather than independent identically distributed draws. Small contexts and ties can yield copies; disclose them.

Run generation seeds17,29,41. One bounded CPU job per seed, at most two concurrent jobs, each with a 15 minute ceiling. Fix tree and linear learners to H001 and H001C. Reuse B002 fitted statistics only after checking its input identity matches H001. Save source ranks, latent draws, row permutations, models, predictions and all quality metrics for every variant. Independent controls and generation reconstruction must pass, and all artifacts must be uploaded and retrieved before another scientific unit.

Primary development comparison is beta rank versus Gaussian rank and versus H001 raw and contextual interpolation. Report correct record counts, class balanced recall, every class recall, conditional distributions, tails, joint queries, copies and diversity separately. Do not call exact marginals complete quality. Broader dependency tests, near copy analysis, further seeds, modern neural references and final confirmation are still promotion requirements.

The nearest primary sources are Segers, Sibuya and Tsukahara, The Empirical Beta Copula, arXiv:1607.04430, definition 2.1 and tied rank discussion; Kiriliouk, Segers and Tsukahara, Resampling Procedures with Empirical Beta Copulas, arXiv:1905.12466; Kojadinovic and Yi, arXiv:2106.10726; and the established marginal rank rearrangement literature. Mechanism sections were inspected. The method is an adaptation and controlled integration of known techniques, not an invented neural architecture or an exact reproduction of their experiments.
